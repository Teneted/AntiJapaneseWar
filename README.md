# AntiJapaneseWar Mod

[![Minecraft Version](https://img.shields.io/badge/Minecraft-1.20.1-green)](https://minecraft.net/)
[![Forge](https://img.shields.io/badge/Forge-47.1.0-blue)](https://files.minecraftforge.net/)

**AntiJapaneseWar** is a Minecraft mod that brings elements of the War of Resistance Against Japan into the game, allowing players to experience historical content in a unique way while remembering the historical events.

## Installation

1. Install Minecraft Forge for version 1.20.1
2. Download the `AntiJapaneseWar` mod file
3. Place the `.jar` file in your `mods` folder
4. Launch Minecraft with the Forge profile
